# Create a Library document

Open Library, then use **+ → New document** on **My documents** or any folder. Write a title and Markdown content, preview the formatting, and choose **Create and save**. The document saves at the clicked location and opens immediately. Root creation does not create a folder. Import uses the same contextual destination.

Blank titles/content cannot be saved. Persistence failures retain the draft for retry; closing a nonempty draft requires an explicit discard action. Documents retain durable IDs, revision history, content search, Markdown export, conversation attachments, origin links, and retained citation snapshots. The document menu offers revise/rename, move, history, export, and Trash. Drag a title onto a folder or My documents to move it; the Move dialog is the keyboard alternative.

See [Library folders](library-folders-design.md) for the complete layout, legacy migration, and acceptance contract.
