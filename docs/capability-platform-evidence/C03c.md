## Implementation boundary

The public board adapter now forwards selected references to the existing native owner instead
of rejecting every nonempty source list. Its existing pre-await JSON copy and envelope validation
remain intact. Native C03a owns canonical metadata, installation, permission, revocation and content
bounds; there is deliberately no extra renderer document read that could break committed replay
after revocation. Creation still produces a todo without execution authorization.

The canonical contract, Skill and starter minimum version document this boundary, including stable
intent persistence before the first attempt, exact committed replay, 50 unique sources and the
8,000,000-byte aggregate snapshot-body limit. A scoped independent review of forwarding, native
authorization and replay found no concrete issue; production hostile-package isolation was outside
that review and remains unfinished.
