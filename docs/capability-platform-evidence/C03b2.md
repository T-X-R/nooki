## Behavior and transaction boundary

Task cards retain typed selected references without aliasing caller-owned nested objects.
Their citation buttons forward the full selected identity to the existing Library navigation;
captured tasks add their snapshot ID so retained task input takes precedence. Plain references
continue to open the current Library document until captured. Open and remove are separate
keyboard-accessible controls.

Explicit delegation of an existing legacy/capability todo now uses the native worker's `delegate`
operation. Under the task-data lock it compares the reviewed title, description and full sources,
durably binds the request identity, captures the selected bodies, and commits authorization plus
queued state. It does not convert the task to Goals or introduce another execution engine.
The existing dispatcher remains responsible for later execution under its normal queue controls.

A pending receipt binds the exact request before any snapshot can survive a failed queue commit.
Capture failure leaves the card idle with no authorization, although pending receipt metadata and
the board write token may change. Changed content requires a new review/request identity; exact
committed replay returns the current board and cannot requeue a withdrawn or removed task. Every
delegation write establishes a stale-write fence, including boards with only legacy tasks.
The native receipt ledger is retained across legacy writes, bounded at 1,024 entries including
pending requests, and rejects new identities at capacity without evicting existing replay history.
Requests are bounded at 64 KiB; source capture retains C03b1's 50-source/8 MiB bounds. The existing
legacy conversation context limit is unchanged; this is not an 8 MiB agent-input guarantee.

This is a trusted user-control integration, not a new public capability permission or hostile
renderer boundary. Production containment remains R02/R03/K4. Public sourced creation and kit
delivery remain C03c; no contract/kit version changes are claimed in this slice.

## Reproduction and verification

- Native board suite: **31 passed**. New cases cover original-content delegation after revoke,
  changed reviewed content, missing captures, replay after withdrawal, stale legacy writes, and
  snapshot survival across a failed queue commit. Full native regression: **200 top-level passed**,
  plus one existing nested child result; two existing live-agent tests ignored.
- JavaScript regression: **172 platform + 5 capability tests passed**. The two new store/adapter
  tests first reproduced aliased selected references and the missing full-source delegation path.
- Three bounded independent review cycles found and then verified fixes for withdrawal replay,
  legacy-only stale writes, and unbound snapshots after failed commit. The final review reported
  no further concrete issues. Red reproductions are retained in `/tmp/nooki-c03b2-review-red.log`
  and `/tmp/nooki-c03b2-binding-red.log`.
- The first full native run failed three socket/worker tests under sandbox restrictions. The
  rerun with local IPC permitted passed; no test was weakened to bypass that restriction.
- Production TypeScript/build and fixture type-check pass. The older task-board UI fixture was
  updated for the native delegation operation and syntax-checked; its full browser suite was not run.

Browser verification used the [real component fixture](../../tests/ui/fixtures/task-sources/README.md)
with simulated navigation. Enter emitted all five selected-reference fields. Adding a captured task
added `snapshotId` without dropping the grant identity. Tab moved from Open to Remove; Enter on
Remove removed the row without changing the last open event. The plain control emitted its current
document reference. At 320×700, Chinese light and dark views were inspected: no horizontal overflow,
title ellipsis and separate controls remained visible (open bounds 57–260, remove 270–296 CSS pixels).
No captured application warnings/errors. These observations do not establish native document reads.

Installed-app acceptance could not proceed because the native desktop control interface repeatedly
reported a session-lock transition; see [the attempted same-window run](P02-attempt.md).
The [native source fixture](../../tests/fixtures/task-sources/README.md) is prepared but has **not**
been run. Native citation opening, actual click-to-delegate, failure display and restart remain required.
