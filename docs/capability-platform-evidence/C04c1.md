## Delivered boundary

`host.board.requestSelection` accepts a purpose, `['attachDelivery']` and a 1–50 selection limit.
The controller derives recipient identity/version from the Host, checks the declared
`board.attach-delivery` permission and rejects unsupported operations/preview. Native command
bindings derive the caller from the actual webview. C04b1 remains the authority for installation,
restore epoch, exact item versions, grant persistence and revocation.

The application mounts a host-owned task picker. It loads current native tasks and displays package
identity, purpose and attach-only scope. Selected IDs and displayed revisions are confirmed together;
the client freezes the approved references before dispatch and rejects changed confirmation retries.
Descriptions and full task identifiers for duplicate titles distinguish otherwise identical choices.
Switching language does not reload or replace displayed/approved task versions. Results contain
only grant metadata, item IDs, revisions and titles, without descriptions or execution authority.

The client captures focus before asynchronous issuance, reuses the existing delayed focus-restoration
helper, cleans up by correlation after lost issuance replies, and closes the picker when disposed.
It checks activity again after confirmation and cleanup so late completion cannot reach a disposed
package Host. Lifecycle invalidation includes the new selection client. A dismissed unconfirmed
selection creates no grant; closing a Host does not undo an approval already durably granted by the
user. Explicit revocation remains available in the task-board access manager.

The manager shows active, stale, inactive and revoked grant records and supports durable revocation.
Removing access preserves tasks and prior deliveries. Its Escape handler does not also close an
underlying task detail panel. Selection/access dialogs reuse the existing native HTML dialog and
Library dialog styling; loading/error/retry/empty states are implemented. Their actual keyboard,
focus and layout behavior is not yet verified by this receipt.

Native manifest validation and exported-kit checking require `minPlatformVersion: "0.8.0"` for the
new public permission. Contract types, preview refusal, installer permission copy and developer Skill
are aligned. The public contract explicitly states that attachment submission is not exported in
this increment; obtaining a selection neither attaches content nor executes/accepts a task.
