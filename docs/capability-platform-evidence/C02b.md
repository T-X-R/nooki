## Delivered behavior

`host.library.requestSelection` supports saved Markdown document snapshots. The host displays the
recipient, version, purpose, selected count and a clear sharing notice. A package receives either
`dismissed` or selected grant metadata; it reads snapshot content through `documents.readSelected`.
It cannot supply the recipient or obtain the entire Library through the selection result. Unsupported
artifact/media requests fail explicitly. The portable preview returns `UNSUPPORTED_SERVICE`.

A private native selection session captures the current installation generation before opening the
picker. Commit checks that same authority and freezes the approved document IDs for retries. The
host's request correlation allows cleanup when the issuance reply is lost; abandoned sessions expire
after 15 minutes and are capped at 16. Cancellation is idempotent. A committed durable grant can
remain after cancellation; cancellation does not undo an already accepted effect. A disposed Host
cannot reopen the picker or receive a late successful selection, including during asynchronous cleanup.

Library → Document access lists metadata and active/inactive/revoked status and lets the user revoke
future package reads. Retained citations remain user-accessible. C02a supplies durable immutable
snapshots and revocation. The existing manual authorize-and-open flow remains a legacy trusted path;
this receipt does not claim it has the new pending-session behavior.

This is still a trusted shared-realm package runtime. Main-webview checks protect the new controller
from other native views, but do not isolate hostile code already executing in the main realm. Actual
production caller containment remains R02/R03/K4. The P02 same-window feasibility receipts are separate.

## Actual installed-app observations

Profile: `/private/tmp/nooki-profile-tu8kzH`; installed `/Applications/Nooki.app` 0.5.0.
All three archives were imported through the native file chooser and manifest permission consent UI.
Only synthetic Alpha/Beta documents were used; the profile disables agent execution.

| Case | Observed result |
| --- | --- |
| Empty Library | Empty message; authorization disabled; recipient, version and purpose visible |
| Explicit cancel | Returns `dismissed`; zero grants before the first approval |
| Search and limit | No-match message; clearing search restores entries; choosing one disables the other at limit 1 |
| Reader selection | Alpha alone selected and read; result metadata contains only the selected reference |
| Job selection | Fresh unchecked picker, Beta selected; job completes with metadata and Beta reads successfully |
| Foreign grant | Peer has read-selected permission but reader's Beta grant returns `PERMISSION_DENIED` |
| Independent positive control | Peer separately selects Beta, receives a different grant and reads the same synthetic content |
| Missing permission | Storage-only denied package returns `PERMISSION_DENIED` without opening the picker |
| Invalid/unsupported input | Forged recipient returns `INVALID_INPUT`; artifact request returns `UNSUPPORTED_SERVICE` |
| Disposed Host | Peer schedules an 8-second call, navigates to Library, then returns: old Host result is `CANCELLED` |
| Access manager | Chinese light view shows recipient/version/purpose and active status |
| Visual selection | Chinese light wide view and English dark narrower window display all controls without clipping |
| Restart | Full app quit/restart retains reader Beta grant; public read returns the original snapshot |
| Revoke and retain | Reader Beta becomes Revoked; its next public read is denied; Open retained citation displays the original Beta snapshot |
| Fresh picker state | Subsequent picker starts at zero selected; explicit cancellation returns `dismissed` |

Three native grant records were independently checked: reader Alpha, reader Beta and peer Beta, each
with one snapshot and a private installation generation. The two Beta contents have the same SHA-256
but different recipient grant IDs. The state summary is retained at
`/tmp/nooki-c02b-native-state-before-revoke.json`. The [retained post-revoke state summary](C02b-native-state.json) confirms only reader Beta has a revocation marker and all three snapshot content hashes remain unchanged.
