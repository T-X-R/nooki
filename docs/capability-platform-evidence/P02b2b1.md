## Change and reproduction

The experiment now supplies a native `WKWebViewConfiguration` before view creation. Each configuration
has its own nonpersistent data store. For restricted views, it sets an empty allowed-network-host
set, disables network subresources, peer connections and DNS prefetch, and checks all getters before
navigating from `about:blank` to the package fixture. The unavailable-selector view never navigates.
This replaces the old post-creation preference callback; no production loader uses these controls.

The explicit store is necessary: the pinned Wry `wkwebview/mod.rs` supplied-configuration branch uses
`configuration.websiteDataStore()` and does not apply the separate `incognito` option. All five
configurations report nonpersistent stores, and package markers remain separate during peer writes.

The probe uses already-transitive `objc2` 0.6.4 and `objc2-web-kit` 0.3.2 as macOS development
dependencies for the typed configuration builder. No dependency version was upgraded. Cargo rewrote
the lockfile header from version 3 to 4; the only dependency-list additions are these two root entries.

Build with `cargo build --offline --example capability_runtime_probe` in `src-tauri`; use the temporary
bundle procedure from [P02a](P02a.md) and a fresh `scripts/desktop-profile.mjs create` profile. The
measured runs used:

```sh
node scripts/desktop-profile.mjs launch /private/tmp/nooki-profile-WmvA1b '/tmp/nooki-p02b/Nooki Runtime Probe.app/Contents/MacOS/probe'
node scripts/desktop-profile.mjs launch /private/tmp/nooki-profile-Csd71a '/tmp/nooki-p02b/Nooki Runtime Probe.app/Contents/MacOS/probe'
```

Use newly created profiles when reproducing, rather than these historical paths. In the first run,
select shell, run channel scope first, then boundary probes; play audio in A, switch to shell and
request status, run additional network probes, return to A and pause/release. Quit normally. In the
second run, run boundary probes, start A's infinite loop, request status, destroy A, request status
again and quit normally. Both measured runs exited with code 0 before the five-minute watchdog.

Only synthetic fixtures, silent PCM data and loopback receivers were used. The first attempt to
launch the second run inside the execution sandbox terminated without fixture events; the measured
run used desktop execution outside that sandbox. No ordinary profile or agent credentials were used.

## Observed boundaries

| Check | Observed result |
|---|---|
| Receiver controls | All fifteen native self-checks pass: HTTP, dedicated preconnect and UDP for each of five views |
| Restricted network | Shell and A with CSP/native controls, and B with native controls but no CSP: zero observed HTTP, UDP or preconnect connections |
| Permissive positive control | Thirteen HTTP paths each received once: fetch, beacon, socket, image, frame, style, preload, script, eventsource, worker, form, media, navigation; eight UDP packets and one preconnect connection |
| Configuration ordering | Restricted getters report host count 0 and all three Boolean controls false before package scripts start; unsupported selector reports `readyForPackageNavigation: false` and no package script event |
| Public/native boundary samples | Forged owner, unlisted application command, shell-only control and sampled core title mutation denied; exact 0/1,024/65,536-byte echoes pass; oversized payload denied |
| Local resources/storage | SVG loads at 16×16, WAV duration is 60 seconds; A/B cannot read the shell marker and each retains its own marker after peer writes |
| Internal channel | Foreign A/B/control reads fail at 225,790–225,794 ms while the owner's message is pending; shell receives exactly 9,027 bytes at 228,265 ms |
| Playback across focus loss | A advances from 0.166 seconds at 250,236 ms to 10.835 seconds at 261,014 ms; second sample is unfocused, playing and not ended |
| Pause/release | At 282,058 ms: playback stops advancing, paused true, ready/network states 0, `src` attribute absent. WebKit retains the historical `currentSrc` string |
| Forced stop in fresh run | A heartbeat freezes at 110; shell/B advance from 110 to 179 and control from 111 to 180. A PID 77311 reaches 99.4% CPU. Destroy requested at 55,973 ms; A absent at 59,090 ms and PID gone; shell 77308, B 77312 and control 77314 remain alive |

The 3.117-second stop observation interval is not a precise destruction latency. Private process IDs
are diagnostic only; Tauri window destruction performs the stop. The first run's late timestamps
include time awaiting UI observation and are not startup-performance measurements.

The native-only B result distinguishes native network restrictions from CSP rejection, but does not
isolate the contribution of each individual native setting. Its WebSocket/EventSource constructors
succeed while receivers remain empty; constructor success is not network success. Its blob worker
fails to load, while the permissive control's worker fetch reaches the receiver.

## Limits and remaining decision

This closes the reproduced preconnect escape from P02b2a on the measured engine. It does not certify
all networking APIs, future WebKit releases or other operating systems. WebTransport,
WebSocketStream and prefixed peer connections are undefined even in the permissive control.
Service-worker registration rejects the custom scheme in the control, link prefetch has no positive
traffic, and DNS-prefetch has a false native getter but no packet-level positive control. These are
unavailable/inconclusive paths, not additional policy passes.

All native selectors are private SPI. Missing selectors/readback mismatch fail closed in this probe;
supported-engine policy and production use remain undecided. Separate windows still do not prove
integrated toolbox-page behavior. IPC samples do not establish allocation or queue budgets; media
state does not establish native file-descriptor release, audible output or all codecs. Production
channel generation/closure semantics and remaining framework exceptions still require audit.
