## Delivered boundary

Six registered Tauri commands connect proposal, cancellation, target discovery, commit and retained
draft list/read to the existing native owners. They derive caller identity from the actual Webview
label and require the main Host view. They do not isolate hostile code sharing that view; production
realm isolation remains a separate gate. No package conversation-history or general read API is added.

Target discovery returns only bounded IDs/titles, a cursor and a partial-catalog flag. Archived and
task-owned conversations are excluded. Current ordinary targets use the existing local conversation
catalog or the existing Codex active-workspace listing, with at most 128 pages for commit validation.
Incomplete catalogs and cyclic pagination report unavailability instead of falsely declaring a
target absent. New offers need no conversation connection or Agent session.

Approval freezes the target before asynchronous discovery. Current installation, restore scope and
pending-review lifetime are checked before and after discovery and again at the write boundary.
No lock spans the asynchronous lookup. The task-owned exclusion is repeated under the effect's data
lock. Exact committed retries return their receipt without another target lookup or source capture.
Host-only reads retain user-owned drafts after producer removal; list responses omit text/documents.
Binding errors preserve explicit conflict/uncertainty codes without leaking native paths.

Target validation observes availability; it cannot hold a distributed lock against later external
archive/delete operations. C05b2b must report a disappeared target without silently retargeting or
sending. This slice saves an offer only: it does not navigate, overwrite a composer or send a turn.
Manual adoption/send must use the retained source snapshots, not current Library document IDs.

## Verification and review

Nine integration tests exercise the actual native owner/controller/store:

- New offer and exact replay require no conversation workspace, session or task creation.
- Actual local catalog discovery returns metadata only; archive refuses a new commit, restore allows
  it, and deletion after commit does not prevent exact receipt replay or retained-draft reads.
- Foreign callers and dismissed reviews fail before discovery or draft access.
- Native task-owned conversations are excluded and cannot receive an offer.
- Removing the producer preserves Host list/read access to the retained offer.
- Deterministic two-page Codex discovery strips history and uses only initialization/list requests.
- Cancellation during delayed discovery prevents its late result from reaching the review.
- Target changes conflict while validation is pending; disabling the package prevents the late write.
- Partial/cyclic catalogs fail visibly without writing a draft.

One unit test covers sanitized binding errors and pre/post-dispatch uncertainty. The integration tests
use synthetic isolated roots, actual local native catalog files and a deterministic Python protocol
fixture. They do not invoke a real model. The initial missing-module failure is recorded in
`/tmp/nooki-c05b2a-red.log`. A later test reproduced an incorrect missing-target error for a partial
catalog (`/tmp/nooki-c05b2a-partial-red.log`); it passes after correcting the error classification.

- Focused adapter tests: **9 pass**, `/tmp/nooki-c05b2a-focused.log`.
- Full `cargo test --offline --manifest-path src-tauri/Cargo.toml`: **269 top-level plus one nested
  profile child pass**, zero failures, two existing live-agent tests ignored;
  `/tmp/nooki-c05b2a-native.log`. Run with the local socket/process access needed by worker tests.
- `npm test`: **192 platform + 5 capability tests pass**, `/tmp/nooki-c05b2a-js.log`.
- Source review covers actual Webview binding, immutable approval, receipt replay, cancellation and
  lifecycle races, native target ownership, bounded pagination and error classification.

The tests call the same functions used by the registered commands; registration and command wrappers
were compiled and inspected. Actual UI-to-Tauri interaction, keyboard/focus behavior, public SDK
lifetime handling and independent installed ZIP handoff were not exercised in this slice.
