## Delivered scope

The canonical contract continues to export only existing Host operations and current document,
publication and conversation-input types. The unsupported `widget` entrypoint is removed from its
public type; runtime/checker rejection already existed. Future board/chat/agent APIs remain absent.
There is no separate negotiated API version yet: consumers record the kit and Nooki versions.

The exported starter's `preview/host.ts` is a deterministic, reusable simulation of JSON storage
and environment subscriptions. Each instance starts empty, enforces the storage permission and
copies JSON values. It reads no browser storage, native configuration or credentials. Reload resets
the simulation. Desktop-only operations reject explicitly, including grant listing, task observation
and reference opening, which previously returned empty values or displayed an alert. The toolbar and
contract describe this boundary. This is not a mock implementation of the future service catalog.

Kit 0.2.0 records the changed development behavior. Existing source projects are not overwritten;
authors must copy useful preview text before updating an older starter. Desktop package data is
unchanged. The generator still copies canonical definitions rather than maintaining another SDK.
