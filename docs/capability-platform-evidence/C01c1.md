## Native boundary

`grant_board_creation` now requires the enabled, exact-version installed manifest to declare
`board.create`. The worker independently checks that permission in the current registry under
the existing authority fence at commit. Removing the permission denies an old handle even if a
restored registry retained the generation. Permission declaration alone does not issue authority:
the trusted native controller must still make the grant decision. There is no renderer issuance
command in this increment.

The registered `capability_board_create` command takes a Tauri-injected `Webview` and derives its
caller from `webview.label()`. Its `request` contains only `handle`, `key` and `input`; outer fields
such as caller, capability ID, generation, grants, operation and resource are rejected. The adapter
constructs the fixed private worker envelope. The existing worker transaction derives package
identity from the invocation record and requires current authority for creation and replay.

The adapter and worker share the same request validator. Both the incoming request and the internal
envelope must fit 65,536 serialized UTF-8 bytes. Existing title/description/key limits and empty-only
sources remain unchanged. Unknown content fields are rejected before dispatch. The initial authority
check avoids sending foreign/revoked requests to the worker; it releases its fence before IPC.
The worker rechecks authority at the effect, so the initial check is not a lease. There is no await
inside an authority callback.

The boundary returns the existing `{id, revision: 1}` receipt, validates that result shape, and
serializes errors as `{code, message}`. Known policy/validation/conflict/capacity errors retain their
codes with fixed messages. Native filesystem paths, raw handles and worker diagnostic strings are
not forwarded. Unclassified worker transport errors and malformed replies become `OUTCOME_UNKNOWN`,
because an effect may have committed before its reply was lost. Retry guidance preserves the same
key and input; no automatic retry or fresh key is generated. Unclassified failures before dispatch
become `RESOURCE_UNAVAILABLE`.

These are admission checks after Tauri JSON decoding, not bounds on receive allocation or total
memory. The unchanged legacy worker framing and shared renderer remain trusted-only. Two legacy
packages in the same WebView do not acquire distinct native identities from this adapter. R02/R03
still own actual isolated runtime identity and containment.
